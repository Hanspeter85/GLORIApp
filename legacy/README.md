# Legacy scripts (GLORIA-MRIO_Parser, v059)

These are the original scripts of the repository `GLORIA-MRIO_Parser` on which
GLORIApp is built. They are kept for reference and for reproducing earlier
analyses (Ecological Unequal Exchange, North-South trade, multipliers, ...).
They are **not** used by the app. Their paths (`/home/RegIOLab/...`) refer to
the old server setup.

The new, reusable parser lives in `parser/`, the calculation engine in `R/engine.R`.
